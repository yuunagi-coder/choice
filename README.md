# CHOICE.
なかなか決められない…という人のために小さな2択、3択…を一つに決めるアプリ。ランダムな結果をきっかけに本音に気づくために作成しました。

## コンセプト
答えはもう決まっているのかもしれない
迷いの中に、もう答えはある
選ぶきっかけをひとつ

決断とは、選ぶことではなく自分の気持ちに気づくこと
Choice.はランダムな結果をきっかけにあなたの”本当の答え”を引き出すアプリ

## 公開URL
https://yuunagi-coder.github.io/choice/

## 機能
- 選択肢登録
- ランダム選択
‐ 結果表示(名言付き)
- 再選択ボタン
- X投稿
